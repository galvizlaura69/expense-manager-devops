1. Introducción

Expense Manager es una aplicación web desarrollada con Django 5.2 y Python 3.12 diseñada para el control financiero personal. Permite a los usuarios autenticados administrar sus ingresos y gastos mediante operaciones CRUD sobre categorías y movimientos financieros, con una separación clara de la información por usuario.

El proyecto integra prácticas de DevOps: contenedorización con Docker, orquestación con Docker Compose, integración y despliegue continuo con Jenkins, y organización del código bajo la estrategia GitFlow.

4. Modelo de Datos

4.1 Tabla: categories

CampoTipoDescripción
idAutoField (PK)Identificador único
nameCharField(100)Nombre de la categoría
typeCharField(10)Tipo: INCOME (Ingreso) o EXPENSE (Gasto)
user_idForeignKey (User)Usuario propietario
created_atDateTimeFieldFecha de creación automática

Restricción: Un usuario no puede tener dos categorías con el mismo nombre y tipo (unique_user_category).

4.2 Tabla: transactions

CampoTipoDescripción
idAutoField (PK)Identificador único
descriptionCharField(200)Descripción del movimiento
amountDecimalField(12,2)Monto del movimiento (debe ser positivo)
dateDateFieldFecha del movimiento
category_idForeignKey (Category)Categoría asociada (PROTECT)
user_idForeignKey (User)Usuario propietario
created_atDateTimeFieldFecha de creación automática

Restricción: El monto debe ser mayor a cero (transaction_amount_positive). Una categoría con transacciones no se puede eliminar (PROTECT).

4.3 Tablas del sistema de Django

Además de las tablas propias, Django crea automáticamente:

  • auth_user: Usuarios del sistema
  • django_migrations: Registro de migraciones aplicadas
  • django_content_type: Tipos de contenido
  • auth_group y auth_permission: Sistema de permisos
  • django_session: Sesiones de usuario
  • django_admin_log: Historial del panel de administración

6. Pipeline CI/CD con Jenkins

EtapaDescripción
Checkout SCMObtiene el código fuente del repositorio GitHub.
CheckoutPrepara el workspace de construcción.
Build Docker ImageConstruye la imagen Docker con docker compose build.
Django CheckEjecuta python manage.py check para validar la configuración.
Run TestsEjecuta pruebas automatizadas con python manage.py test.
DeployDespliega la aplicación solo en la rama main.

Trigger: El pipeline usa pollSCM para revisar periódicamente cambios en el repositorio.

¿Dónde queda el deploy? En el mismo servidor donde está Jenkins, disponible en http://localhost:8000 (o la IP del servidor).

7. Diseño de Interfaz (UI/UX)

  • Paleta de colores: Verde esmeralda (#10b981), verde oscuro (#047857), blanco y fondos degradados verde claro → blanco → verde claro.
  • Tipografía: Inter para jerarquía visual clara.
  • Componentes: Tarjetas elevadas con sombra, botones con gradiente verde, tablas con filas zebra, badges de tipo (ingreso/gasto).
  • Mensajes de éxito: Fondo verde claro, borde izquierdo verde, ícono de check.
  • Mensajes de error: Fondo rojo claro, borde izquierdo rojo, ícono de alerta.
  • Responsive: Se adapta a pantallas móviles.

8. Registro de Usuarios y Autenticación

  • Formulario CustomUserCreationForm con campos: usuario, email, contraseña y confirmación.
  • Vista signup que crea la cuenta, inicia sesión automáticamente y redirige al dashboard.
  • URL /signup/ con nombre signup.
  • Plantilla templates/registration/signup.html con el mismo estilo verde/blanco.
  • Todos los inputs y selects ocupan el ancho completo en login, registro, categorías y movimientos.

10. Conclusión

¿De qué se trata el proyecto?

Expense Manager es una aplicación web para el control financiero personal desarrollada con Django y Python. Permite registrar, consultar, actualizar y eliminar ingresos y gastos, organizados por categorías. Cada usuario tiene su propia información aislada, y puede consultar en un dashboard el resumen de ingresos totales, gastos totales y el balance disponible. El proyecto incorpora prácticas DevOps como contenedorización con Docker, pipeline de CI/CD con Jenkins y organización del código mediante GitFlow.

¿Por qué es útil?

  • Control financiero personal: Ayuda a los usuarios a llevar un registro ordenado de sus entradas y salidas de dinero.
  • Toma de decisiones: Al visualizar ingresos, gastos y balance en un solo lugar, es más fácil planificar gastos y ahorros.
  • Separación por usuario: Cada persona accede solo a su propia información, garantizando privacidad.
  • Automatización DevOps: El pipeline de Jenkins construye, prueba y despliega la aplicación automáticamente, reduciendo errores humanos.
  • Interfaz amigable: El diseño verde y blanco con gradientes, tarjetas, mensajes de error y éxito bonitos hace que la aplicación sea agradable y fácil de usar.
  • Portabilidad: Al estar contenedorizada con Docker, la aplicación se puede ejecutar en cualquier entorno sin problemas de dependencias.
En resumen: Expense Manager cumple con los requisitos de una aplicación de gestión financiera personal, integrando desarrollo de software con prácticas DevOps modernos, y ofrece una herramienta útil, usable y automatizada para el control de gastos e ingresos.
